I've created a special tool to help you optimize your image for better performance:

1. Open `image-optimizer.html` in your browser
2. Upload your image
3. Adjust quality and size settings
4. Click "Optimize Image"
5. Download the optimized version
6. Replace the existing image in the `images` folder with this optimized version

## Best Practices for Portfolio Images

- **Recommended Size**: 500x500 pixels for profile images
- **File Format**: JPEG for photos, PNG for graphics with transparency
- **File Size**: Keep under 200KB for optimal loading speed
- **Quality Setting**: 80-90% usually provides a good balance between quality and file size

## Additional Tips

- Make sure your image has the correct filename (profile.jpg)
- Consider using a square image for best results with the circular crop
- If you change the image filename, update the src attribute in index.html
